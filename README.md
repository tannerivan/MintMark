# MintMark™

**The coin collector's first call.**

Type in any US coin — year, mint mark, denomination — and instantly get every known error, variety, key date status, grade ceiling, grading recommendation, and estimated value range. Powered by AI, cross-referenced against numismatic databases.

Built with Next.js, Neon PostgreSQL, Clerk, Anthropic API, and Stripe.
